    How to integrate

    Drop the page into a FastAPI app, a static site, or a larger frontend. The theme is already self-contained.

    1. 1

      Serve the file from your backend or static host

      Keep the page on the same origin as the API when possible. In this repo, app.py already serves public/test.html at /.

    2. 2

      Point the form at POST /api/v1/torrents

      Send { magnet }, or the accepted aliases magnet_link and link. The response returns the torrent object and stream URLs.

    3. 3

      Render the returned files and stream links

      Use torrent.files, torrent.stream_url, torrent.playlist_url, and torrent.download_url to populate your file tree and players.

    4. 4

      Embed the player anywhere

      Open the playlist URL in VLC, MPV, or use HLS.js in a custom web player. The page already exposes the links you need.

    Drop-in HTML example

    Use this pattern in any frontend that needs to hand a magnet to the backend and immediately open the resulting stream.

    <script>
  const API_BASE = window.location.origin;

  async function addTorrent(magnet) {
    const response = await fetch(`${API_BASE}/api/v1/torrents`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ magnet })
    });

    if (!response.ok) {
      throw new Error('Unable to add torrent');
    }

    const torrent = await response.json();
    return torrent;
  }

  async function openStream(magnet) {
    const torrent = await addTorrent(magnet);
    window.open(torrent.playlist_url || torrent.stream_url, '_blank');
  }
</script>

    API response shape

    The public API returns a torrent object that is ready to feed into a UI or media player.

    Endpoint
    POST /api/v1/torrents
    Payload
    { "magnet": "magnet:?xt=urn:btih:..." }
    Primary fields
    id, name, status, progress, files
    Playback links
    stream_url, playlist_url, and download_url

    Backend wiring

    The root route in app.py serves this file, and the public API lives under /api/v1.

    Root page
    GET / returns public/test.html
    Static assets
    /public is mounted as a static directory
    CORS
    Allowed for all origins in the current app setup
    Player usage
    Open the playlist URL in a browser, VLC, MPV, or any HLS-capable client
